# Pebby documentation

The root [README](../README.md) is the project entry point. These documents keep
implementation contracts, experiment records, and validation evidence close to the
code without making the onboarding page a research notebook.

  boundaries.
- [Agent and training](agent-and-training.md) — policy/world-model design, datasets,
  training commands, experiment ledger, and metric interpretation.
- [Viewer and HostAI integration](viewer.md) — local viewer operation and the HostAI
  runtime contract.
- [Seven reference difficulties](seven-reference-difficulties.md) — current public
  generation profiles, resumable commands, and calibration evidence.
- [Generated-level and collection fixes](generation-quality-v2.md) — historical
  five-tier generation and collection work.
- [World-data failure and route coverage](world-failure-coverage.md) — failure and

- [UI and server validation](validation.md) — automated/browser checks and their
  limitations.
- [Development notes](development.md) — layout, checks, provenance, and licensing.
