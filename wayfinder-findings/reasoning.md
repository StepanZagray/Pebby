## Answer

Current evidence does **not** establish that Pebby is too small. It establishes poor primitive transfer, an unreliable distance/comparator interface, and absent persistent memory and action-sequence simulation. Test these separately. First establish goal-conditioned navigation with a controlled curriculum and a matched width comparison. If short-route fitting succeeds but longer obstacle routes fail, compare learned spatial recurrence. Introduce memory after demonstrating public-history ambiguity; consider full learned-world-model control only after reliable primitives and multi-step model qualification.

“One action ahead” describes the predictor's transition horizon, **not the horizon of its supervision**: remaining-route distances and optimal-action labels already incorporate downstream consequences. A reactive policy can in principle learn long-horizon decisions. Missing explicit search is therefore a plausible generalization limitation, not proof of impossibility.

## Method evidence and limits

All web sources below were retrieved and their cited locators checked on **2026-09-13**. Each is owning-primary; each LS20 application is inference.

**F3 — VIN/GPPN: supported; high confidence within tested mazes.** VIN embeds approximate Bellman updates as recurrent convolution/max operations, trained from expert actions; the grid experiments use obstacle/goal maps and compare complete trajectories on held-out maps. Its iteration count is spatial propagation depth. [Tamar et al., VIN, §3.1, §4.1, pp. 4–6](https://arxiv.org/pdf/1602.02867), 2016 paper, arXiv v4 revised 2017-03-20. GPPN replaces the recurrent update with gated LSTM computation and reports better optimization/generalization on its maze suite. It explicitly compares parameter-adjusted widths and varies kernel size, iterations, seeds and dataset size. [Lee et al., GPPN, §3, §5.1–5.5, pp. 2–5](https://proceedings.mlr.press/v80/lee18c/lee18c.pdf), ICML 2018.

**Applicability:** a learned spatial route module is a close experimental match for obstacle navigation. **Limit:** ordinary position-only maze values cannot represent all LS20 glyph, budget, collected-goal and reset dependencies. Neither paper proves LS20 success. Gated spatial recurrence inside one decision also supplies no cross-action episode memory. Increasing iterations changes computation; larger kernels can propagate farther per iteration, so iterations are not interchangeable with physical moves.

**F4 — MuZero: supported; high confidence for algorithm, low for Pebby cost/benefit.** MuZero learns recurrent latent transitions plus reward/value/policy predictions and trains them through real action sequences; search produces improved policy targets. Its experiments distinguish five training unroll steps from 50 Atari or 800 board-game search simulations. [Schrittwieser et al., §3–4, Figure 1, pp. 3–4](https://arxiv.org/pdf/1911.08265), 2019 preprint. **Applicability:** it supplies an explicit mechanism for testing candidate action sequences. **Limits/prerequisites:** Pebby's outcome distributions are not a reusable next latent board; adding search around the current heads does not create MuZero. Need latent transitions, reward/termination contracts, trajectory replay, model-error checks and search targets. The paper's large budgets are not a minimum requirement or an LS20 estimate. Known-rule supervision makes a smaller controlled planner experiment more informative first.

**F5 — Dreamer: supported; high confidence for algorithm, low for LS20 transfer.** DreamerV3 jointly trains a recurrent world model, actor and critic from replay; behavior improves on imagined latent trajectories. This is distinct from scoring one-step decoded outcomes or performing per-move MCTS. [Hafner et al., “Learning algorithm,” “World model learning,” “Actor critic learning,” Figure 3](https://arxiv.org/html/2301.04104v2), 2024-04-17 revision. **Applicability:** sequence-state learning and imagined behavior updates are relevant if visual dynamics and long-term credit assignment become the bottlenecks. **Limits/prerequisites:** requires sequenced observations/actions/rewards/continuations, recurrent-state handling, grounded multi-step predictions and actor/critic training. Published scaling gains belong to that complete system, not evidence that widening Pebby's frozen parent helps. Nature's 2025 publication endpoint failed access; claims here use the identified author manuscript, not an asserted audit of final journal details.

**F6 — temporal memory: supported; medium confidence given accessible revision.** R2D2 studies replaying recurrent networks and shows that initialization, stale stored states and burn-in affect results. Recurrence can also improve representation learning on apparently fully observed tasks; an RNN gain alone does not prove a memory deficit. [R2D2 manuscript, §3, §5–6, pp. 3–5 and 8–9](https://openreview.net/references/pdf?id=Hy7PKCFCQ), ICLR-2019 review manuscript, exact revision date unknown. **Limits/prerequisites:** canonical final PDF was browser-challenged; this accessible primary manuscript is explicitly under review. For Pebby, preserve public observations across actions and specify episode/life/level reset semantics; train contiguous sequences with burn-in or valid initial state. A shuffled-root cache does not teach delayed recall merely because an LSTM was added.

**F7 — hierarchy: supported but qualified.** h-DQN separates choosing a goal from choosing primitive actions until that goal terminates; its Montezuma setup provides custom object candidates and first pretrains the lower controller. [Kulkarni et al., §3 and §4 Setup/Training, pp. 3–4, 7](https://papers.neurips.cc/paper_files/paper/2016/file/f442d33fa06832082290ad8544a8da27-Paper.pdf), 2016. LS20 could expose learned choices such as refill or attribute preparation after navigation is dependable. **Limit:** goal proposals, success predicates and controllers are additional components, not free reasoning. A useful contrary control comes from a separate HRL paper: its revised abstract reports that flat A3C with the same intrinsic reward matched its hierarchical agent on Montezuma. [Dilokthanakul et al., revision note](https://arxiv.org/abs/1705.06769), 2017-11-22. Consequently compare hierarchical teaching against flat policy teaching with the same subgoal information and rewards.

## Decision table: cheapest discriminating checks

These are proposed local experiments; hardware cost remains unmeasured.

| Hypothesis | Controlled comparison | Result that would weaken it | Cost/prerequisite |
|---|---|---|---|
| Missing primitive supervision | Same network/optimizer, ordinary replay versus balanced opposite-goal navigation examples | Neither arm can fit valid tiny cases | Small cached pilot; real-engine verified labels |
| Optimization or conflicting losses | Same inputs/size, joint objective versus policy-only; modest learning-rate sweep and longer fit | Stable small-model training error persists while larger model fits | More updates; record per-module gradients and actual updates |
| Insufficient trainable width | Width 48 versus 96; same encoder/data/topology/objective | Small model reaches comparable training and fresh-layout performance | Count trainable parameters, benchmark memory/time first |
| Spatial computation | Parameter-matched residual CNN versus gated spatial recurrence; route-length-stratified tests | Gains disappear against compute-matched CNN or occur only on memorized maps | Additional module; common inputs/labels; sweep depth independently |
| Missing memory | Identical H8 inputs from histories requiring disjoint optimal actions; H8 versus recurrent history | Correct history fails to help verified ambiguity cases; absent pairs leave the hypothesis unproven | Construct valid delayed-reveal pairs; sequence replay |
| Multi-step planning | Same learned model with search off/on at several budgets | Deeper search worsens calibrated held-out action choice | Multi-step transitions required before gameplay search |

## Concrete counterfactual capacity experiment

Pre-register a generated primitive corpus: empty matching-goal rooms, then single-obstacle detours; vary player, goal, glyph, orientation and route length. Split by complete layout/identity, keep each counterfactual family within one split, reserve fresh families and longer routes, and replay every teacher route in the real engine. Retain the existing 128 cases as an exposed diagnostic; create a fresh test set.

Fit two freshly initialized planners with the same frozen encoder: current width 48 versus width 96, changing only spatial width. Keep comparator/summary widths, losses, data order, batch size, precision and evaluation fixed; pair at least three initialization seeds. This tests one trainable-capacity direction, not all possible architectures. Start with a tiny memorization subset; then a small fixed corpus. Record training optimal-set accuracy/NLL, per-head losses, gradient norms, actual parameter changes, wall time and memory. Use both equal-example and equal-compute comparisons; give both architectures the same small learning-rate search and a predeclared extension if loss is still falling.

Interpretation: larger-only training fit, replicated after those controls, supports a width/optimization interaction worth pursuing. Small and large fitting equally but both failing new layouts argues against simple memorization capacity as the immediate blocker. A same-size curriculum arm recovering fresh navigation weakens “must be larger.” If both fail tiny cases, validate labels, information access and loss competition before more scale. A policy-only arm succeeding where joint losses fail implicates objectives, not missing parameters. A semantic-input arm tests frozen representation access but changes inputs and is not a pure size comparison. Likewise, a direct goal-conditioned actor is a separate architecture factor: first compare curricula with identical current architecture/objectives, then compare actor interfaces under the winning teaching protocol.

For spatial depth, train a gated module at varied iteration counts and evaluate paths beyond the training-length range. Compare an untied deeper CNN with matched compute as well as matched parameters. A larger receptive field is not proof of learned search. For memory, match **all** runtime inputs including action/validity history: when balanced identical-input pairs require disjoint actions, any stateless policy has at most 50% mean action accuracy on those pairs. An empty-room visible-goal task has no such memory requirement.
